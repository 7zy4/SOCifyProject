# الفريق والأداء

## إنشاء الفريق والدعوات

- ينشئ مسؤول الخادم أول مدير عبر `scripts.bootstrap_team`؛ [خطوات التشغيل](operations.md).
- عند تفعيل التسجيل، اختر إنشاء فريق مستقل أو الانضمام بدعوة. لا تجمع الخيارين.
- يحدد المدير بريد المدعو ودوره، ثم يشارك رمز الدعوة معه بنفسه؛ لا تُرسل رسالة تلقائية.
- الدعوة لحساب جديد، مرتبطة بالبريد والدور، صالحة ليوم، وتُستخدم مرة واحدة.
- الحساب مرتبط بمساحة واحدة؛ الدعوة لا تنقل حسابًا قائمًا أو بياناته بين الفرق.
- يتحكم `SOCIFY_ALLOW_REGISTRATION` في التسجيل الجديد، بما فيه استخدام الدعوات.

## الأدوار والوصول

- يضبط المدير أدوار الأعضاء والصلاحيات المسموح بتخصيصها ضمن حدود كل دور.
- لا تمنح شاشة الفريق دور Admin، ولا تسمح بإزالة آخر مدير.
- صلاحيات القراءة والتحديث والتنزيل والمراجعة منفصلة؛ يحسم الخادم الوصول عند كل طلب.
- المشاركة داخل الفريق لا تعني إتاحة كل دليل لكل عضو: يُراعى دور العضو ونطاق القضية وصلاحية دفعة الاستيراد.
- الملاحظات الخاصة تخضع لصلاحيات الاطلاع؛ لا تستخدمها بديلًا عن سياسة حماية البيانات.

## توزيع السجلات والمهام

1. ارفع السجلات داخل القضية وانتظر اكتمال الاستيراد.
2. افتح إسناد سجلات الفريق، وحدد الدفعة والمحلل وتعليمات التحليل.
3. يتابع المحلل المهمة من «مهامي» أو القضية، ويسجل النتيجة والأدلة ثم يكملها.
4. يراجع المدير الحالة الفعلية؛ تُحفظ المهمة والمسؤول والإكمال ضمن سجل القضية والتقرير.

- الإسناد المتكرر للطلب نفسه لا ينشئ مهمة مكررة.
- لا يستطيع عضو إكمال مهمة مسندة إلى عضو آخر دون الصلاحية المناسبة.
- المهام الإلزامية غير المكتملة تمنع إغلاق القضية.
- قبل تغيير المسؤول، راجع الأعمال المفتوحة والتصعيدات والإجراءات التصحيحية المرتبطة به.

## قراءة لوحة الأداء

| العنصر | كيف تقرؤه |
|---|---|
| القضايا النشطة والمهام المعلقة | عبء العمل الحالي، بما فيه العمل القديم |
| أُغلقت خلال الفترة | القضايا التي وقع إغلاقها داخل الفترة المختارة |
| دائرة الإنجاز | نسبة إكمال القضايا التي أُنشئت خلال الفترة؛ ليست نسبة جميع القضايا المغلقة |
| الحركة اليومية | الإنشاء والإغلاق لكل يوم؛ يمكن أن يتجاوز الإغلاق الإنشاء بسبب قضايا أقدم |
| الالتزام بالمهلة | القضايا المغلقة القابلة للحساب وفق سياسة المهلة؛ راجع المقام والتغطية |
| مدد التحقيق | وسيط المدد المقاسة للقضايا المغلقة، مع حجم العينة |
| أداء العضو | العمل المنسوب إليه حسب المؤشر؛ إكمال المهمة يُنسب لمن أكملها |

- اختر الفترة والعضو ثم اضغط «تطبيق».
- اقرأ النسبة مع العدد؛ غياب القياس لا يعني أداءً صفريًا.
- نسبة الفريق تُحسب من مجموع الحالات المقاسة، وليست متوسط نسب الأفراد.
- افتح القضية أو المهمة من اللوحة لمراجعة سبب التأخر واتخاذ الإجراء المناسب.
