# دليل المحلل

## 1. اختر القضية

- افتح القضية المسندة إليك، أو استلم قضية متاحة، أو أنشئ قضية جديدة حسب صلاحياتك.
- تحقق من اسم القضية ومرجعها قبل إضافة ملف أو ملاحظة.
- حدّد النطاق والأصول المعنية؛ اربط كل دليل بالقضية التي يخصها.

## 2. أدخل البيانات

- ارفع الملف، ثم راجع المعاينة والصيغة وتعيين الحقول والمنطقة الزمنية قبل تأكيد الاستيراد.
- انتظر اكتمال المعالجة؛ راجع أعداد السجلات المقبولة والمتجاوزة والأخطاء.
- استخدم موصل القضية لاستقبال السجلات أو سحبها من مصدر HTTPS مجهز.
- إذا فشل الاستيراد، صحح السبب ثم استخدم الاستئناف عند إتاحته. [الصيغ المدعومة](features.md#السجلات-والمصادر).

## 3. راجع التنبيه

- في «المراقبة» رشّح حسب القناة والخطورة والقضية، ثم وسّع صف التنبيه.
- اقرأ ملخصه وافتح تفاصيله عند الحاجة إلى السجلات والأدلة وإجابات التحقيق.
- راجع سبب الكشف ونتيجة النشاط قبل تحديد الحكم؛ وجود تنبيه وحده لا يثبت نجاح الهجوم.
- سجّل التصنيف وسبب القرار وما يحتاج متابعة.

## 4. حقّق ووثّق

- ابحث في السجلات وثبّت الأحداث المهمة كأدلة أو إشارات مرجعية.
- راجع التسلسل الزمني والعلاقات والأصول والمؤشرات ونتائج تحليل الشبكة والأجهزة المتاحة.
- افحص البريد أو الملف عند الحاجة، ثم اربط نتيجة التحليل بالدليل المناسب.
- أضف الفرضيات والنتائج والأسباب الجذرية وأدلة ATT&CK؛ ميّز النتيجة المثبتة عن الاحتمال.
- وثّق منفذ الاستجابة ووقتها ونتيجتها، أو سبب عدم انطباقها. التنفيذ على الأجهزة يتم عبر أدوات فريقك المخولة.
- أكمل المهام وكتيب الاستجابة، وصعّد ما يحتاج إلى عضو آخر.

## 5. راجع التقرير وأغلق القضية

- أكمل متطلبات الإغلاق الظاهرة في ملخص القضية: الأدلة، السبب الجذري أو تعذر تحديده، التحقق من الاستجابة، والمهام والخطوات الإلزامية.
- أنهِ أعمال المعالجة المفتوحة والتصعيدات غير المحسومة، ثم انقل القضية إلى انتظار المراجعة.
- أنشئ التقرير وراجع محتواه والأدلة والأسئلة والإجابات قبل طلب اعتماده من مخوّل بالمراجعة.
- يحتاج التقرير مراجعًا آخر؛ استثناء المدير يتطلب سببًا موثقًا.
- يُغلق المدير القضية بعد اكتمال المتطلبات واعتماد تقرير مطابق لحالتها الحالية.
- إذا ظهرت أدلة جديدة، أعد فتح القضية حسب الصلاحية ثم أنشئ تقريرًا جديدًا؛ يظل التقرير السابق محفوظًا.
- نزّل الصيغة المناسبة: PDF أو DOCX أو HTML أو Markdown أو JSON.

## العثور على دليل

- استخدم بحث السجلات في القضية للعنوان أو الجهاز أو العنوان الشبكي أو النص المطلوب.
- افتح السجل واقرأ الحقول قبل إضافته كدليل؛ عنوان البحث وحده ليس نتيجة تحقيق.
- استخدم المرشحات والإشارات المرجعية لتقليل التكرار أثناء المراجعة.
- [إدارة الفريق والأداء](teams.md) · [استكشاف الأعطال](troubleshooting.md).
