# دليل المحلل والفرز السريع ()

صُممت SOCify  لتعمل كـ**سكين سويسرية** تختصر وقت الفرز الأولي والتحقيق السريع في دقائق:

1. **افتح قضية أو استلم ملكيتها مباشرة:** أنشئ قضية جديدة أو استلم ملكية (Ownership) قضية مفتوحة في مساحة فريقك دون تعقيد أو انتظار موافقة مسبقة.
2. **أدخل السجلات (ملف أو ربط SIEM):** ارفع ملف السجلات (CSV, JSON/JSONL, Syslog, Auth, Web, Sysmon XML, EVTX, PCAP) أو استقبل الدفعة من مصدر SIEM؛ ستعمل القواعد المدمجة تلقائياً لإظهار التنبيهات المشبوهة.
3. **افحص الإيميلات والمرفقات بضغطة زر:** ارفع رسالة `.eml` أو أي ملف مشبوه لإجراء فحص أولي ساكن وآمن يكشف البصمات (`SHA-256`)، وحقيقة نوع الملف مقابل امتداده، والروابط والسلاسل المشبوهة دون تشغيل الملف.
4. **حدّث وطابق قائمة المراقبة (Watchlist):** أضف عناوين الـ IP والإيميلات المشبوهة إلى قائمة المراقبة للرجوع إليها وفحص السجلات والتنبيهات مقابلها فوراً.
5. **أصدر التقرير المنسدل وصعّده للمدير:** بعد انتهاء الفرز، أجب عن أسئلة التقرير عبر القوائم المنسدلة لتوليد تقرير رسمي جاهز للطباعة الفورية، وصعّده مباشرة لمدير مركز العمليات.

## أمثلة استعلامات البحث السريع (Hunt Queries)

```text
severity = critical
event_type = failed_login AND source_ip = "198.51.100.20"
process_name ~ powershell AND NOT outcome = success
mitre_id = T1110
```

محرك الاستعلام مهيكل ومحدد النطاق ولا يقبل حقن SQL أو دوال تنفيذ خارجية.
