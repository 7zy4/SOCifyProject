# V3 — استكمال التسليم وYARA والترحيل

العمل على `socify-version-3` فقط؛ لا تعديل أو دمج `main` أو V2. هذا سجل أدلة، وليس إعلان اكتمال جميع الرحلات الـ75.

## التنفيذ

- تسليم مناوبة بصلاحية المدير و`cases.assign` وإصدار متفائل للقضية، دون تعطيل حساب المصدر أو حذف تاريخه. تنتقل المهام المفتوحة وإسنادات الدفعات والمسؤوليات والإجراءات التصحيحية والتصعيد. يبقى التصعيد السابق محفوظًا وتُنشأ إحالة جديدة. الوصول السابق يبقى فعالًا ومعلنًا؛ الإيقاف وإبطال الجلسات لهما مسار مستقل.
- مكتبة YARA محلية ذات مصدر ورخصة وإصدار وبصمة immutable. يختبر التجميع في خدمة التحليل المعزولة مع أمثلة اصطناعية إيجابية وسلبية قبل النشر. لا includes ولا تحديث أو تنزيل خارجي. حدود المصدر 64 KiB، و100 قاعدة، و1–10 fixtures لكل فئة، و512 KiB مجموعًا. الاختبارات المقدمة لا تثبت تغطية التهديدات أو خلو عينة من المالوير.
- اختيار حزمة YARA عند تحليل عينة، وتثبيت رقمها وبصمتها في العمل ونتيجته والتقرير. نشر إصدار أحدث لا يغير عملًا سابقًا. النتيجة الافتراضية تبقى علامة EICAR الاصطناعية فقط.
- هجرة fixture منشأ بالكود التاريخي الفعلي لـV2، مع نسخة احتياطية وdry run وترحيل مرتين واسترجاع النسخة السابقة. اختُبرت الأعداد والعلاقات والأعمدة الأصلية وفك تشفير الأصل والأدلة وبصماتها وملفات التقارير القديمة. البيانات اصطناعية فقط؛ ليست تجربة على بيانات عميل حقيقية.
- اختُبرت صلاحية suppression بعد انقضاء وقتها دون حذف التنبيه، وحصة الاستيراد ثم الإلغاء واستعادة العامل، وURL كمعلومة دون DNS/اتصال، ومراجعة Postmortem وإجراء تصحيحي بعد الإغلاق مع بقاء ملف التقرير السابق ثابتًا. ترفض المراجعة مسودة سابقة لتغيير القضية وتطلب مسودة جديدة.

## الأدلة الحالية

- 28 اختبارًا لحزم YARA والتسليم وحدودهما، و30 اختبارًا للترحيل والتعافي وTI/Sigma، واختبار التقرير والإغلاق وPostmortem المركب ناجحة.
- رحلتا المتصفح للعمليات وصلاحيات الدفعة ناجحتان؛ تشمل الرحلة الموسعة نشر YARA وتسليم المناوبة وتصدير الحزمة واستعادتها وفحص أرشيفها، بالإضافة إلى TI/Sigma وSLA وMFA. الأحجام 360 و390 و768 و1440 و1920 ضمن هذه الرحلة.
- stack الإنتاجي المحدث: تسجيل دخول HTTP عبر ingress مع CSRF، وعامل استيراد منفصل، وعامل تحليل منفصل، وخدمة native بلا بيانات الشركة أو شبكة. نجح التحليل الافتراضي وحزمة YARA المخصصة واستعادة الحزمة وإنتاج PDF/HTML/JSON/Markdown/DOCX والتحقق من بصمة PDF.
- شُغّل fork المستخدم `7zy4/rea` فعليًا من نسخته المحلية المحتفظ بها على الواجهة النهائية لهذه التغييرات. معرف الدليل `ev_1623961ebb6a861ebbded687eb627b0de9bd26cc55b265919874ff52f18db403`؛ 14 artifact و11 JavaScript، صفر parse failures وصفر integrity contradictions. بقيت 5600 دلالة وأربعة مسارات غير محسومة. الملف المضغوط والـmanifest في `docs/research/v3/`؛ REA ليس شهادة أمن أو تكافؤ تجاري.

نجحت 676 حالة في أول تشغيل شامل، لكن شرط التغطية رفض 89.83%؛ لم يُخفض الشرط. بعد إضافة اختبارات الحدود والفشل الحقيقيين نجحت 691 حالة بتغطية 90.21%، ونجحت اختبارات Chromium الأربعة عشر. كشف تكرار restart سباق جاهزية حقيقيًا رغم نجاح المحاولة الأولى: اتصال مرفوض بخدمة التحليل كان ينهي التقرير مبكرًا. أضيفت إعادة محاولة محدودة بثلاث محاولات وbackoff مقداره 5 ثم 10 ثوان، مع `available_at` وفحص الصلاحيات قبل كل محاولة. لا تعاد تلقائيًا نتيجة تجميع/تحليل غير صالحة؛ النقل المتعذر أو المنقطع فقط مؤهل. اجتاز إصلاح التعافي وحدود التحليل 14 اختبارًا، وأضيفت ست رحلات استيراد فعلية لصيغ Syslog/Linux auth/web/Sysmon/EVTX. يلزم إعادة التحقق الشامل والإنتاجي على هذا الإصلاح قبل اعتماد النتيجة الأخيرة.

## الربط والمراجعة الإضافية

أضيف قرار غرفة التحقيق وربطه بمهمة مصرح بها ودليل من القضية نفسها، مع اختيار المهمة من قائمة قابلة للبحث. ترفض المهام الأجنبية والمعرفات المنطقية. أضيف نطاق فحص مشترك بين واجهة القضية والتقرير: مؤكد/مشتبه/مفحوص ضمن النطاق/غير مفحوص/غير محسوم، وأقدم ملاحظة مدعومة بدليل مع حدودها. لا يسمى ذلك Patient Zero، ولا تُدمج أصول متشابهة الاسم دون دليل. يثبت اختبار مركب ترقية Observable إلى IOC، وتطبيع IPv6 ومنع تكراره داخل القضية، وربط 5 Whys بإجراء تصحيحي، وظهور القرار والمهمة ونطاق الفحص في التقرير الفعلي مع حجب الملاحظة الخاصة.

أضيف رفض أعداد HTTP JSON خارج نطاق SQLite signed 64-bit والقيم غير المنتهية قبل استخدامها، بما فيها المراجع المتداخلة. لا يشمل هذا المنع بايتات ملفات السجلات الأصلية أو القيم الجنائية المؤرشفة؛ يثبت اختبار أن سجلًا يحوي عدادًا أكبر يبقى محفوظًا بأصله. اجتازت الحدود الرقمية وربط الحقائق والتقرير تسعة اختبارات.

نجح اختبار Chromium لتكبير المحتوى CSS إلى 200% وتشغيل النافذة والقوائم القابلة للبحث والتركيز بلوحة المفاتيح. هذا لا يثبت native desktop browser zoom؛ بقي ذلك واضحًا في V3-E57. لم تُضعف CSP لتشغيل أدوات الاختبار.

REA الأخير بعد هذا الربط: `ev_63f72d397bd70fe5fad8d0295584e6eb7ef3079991ed759af97310cde6abdd83`، و14 artifact و11 JavaScript، وصفر parse failures وصفر integrity contradictions، و5632 دلالة وأربعة مسارات غير محسومة. الـmanifest يقيد بايتات الواجهة الحالية؛ الأرقام السابقة في هذا الملف تاريخ checkpoints محفوظ.

مصفوفة القبول أصبحت 64 VERIFIED و11 PARTIAL من 75، وليس 100%. تتضمن البقية عرضًا زمنيًا موحدًا أوسع، وبعض الرحلات المركبة والمنافسة بين مستخدمين، ومراجعة PDF طويل بصريًا، واستكمال قبول التكبير والأداء. `remaining` يصف لكل بند المطلوب تحديدًا؛ لا يُستبدل ذلك بنسبة تغطية الكود.

مراجعة SAST: `S603` في أداة اختبار التعافي فقط موثق كـfalse positive محدد: Docker executable مطلق محلول محليًا، وعمليات محصورة في compose/inspect، واسم مشروع اصطناعي ثابت، و`shell=False`، وبيانات الدخول عشوائية في الذاكرة تمر عبر stdin ولا تسجل. بقي الفحص فعالًا دون استثناء عام. البصمات العامة في manifests راجعت مقابل ملفاتها قبل تسجيل false positives في baseline.
