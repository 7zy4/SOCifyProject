# أدلة كتيبات الاستجابة والتقارير — V3

الفرع: `socify-version-3` فقط. هذه نقطة حفظ تنفيذية وليست إثبات اكتمال الرحلات الـ75.

## السلوك المنفذ

- مكتبة قوالب داخلية: مسودة، نشر من المدير، إصدارات متعاقبة، ستة قوالب إرشادية تظل مسودات حتى المراجعة. نسخة القضية تحفظ الخطوات وإصدار القالب مستقلين عن تحديث المكتبة.
- الخطوات مخصصة حسب الدور؛ الإكمال الإلزامي يحتاج دليلًا من القضية، والخطوة الحساسة تنتظر اعتماد المدير. لا تنفيذ أوامر على الأجهزة ولا احتواء وهمي.
- تقارير ثابتة من بيانات القضية: الملخص والنطاق والأصول والمؤشرات والفرضيات والخط الزمني والتصعيد والإجراءات و5 Whys والتوصيات وMITRE والمهام وفهرس الأدلة وبصماتها. السجلات الكاملة لها تصدير مستقل؛ لا تُحذف صفوف بصمت لتناسب التقرير.
- صيغ JSON وHTML وMarkdown وDOCX وPDF، بالهوية والخطوط المحلية في HTML/PDF، ومن دون hyperlinks أو macros في DOCX. يحتفظ ملف DOCX بأسماء خطوط الهوية؛ عرضها يتطلب تثبيت الخطوط على جهاز قارئ الملف.
- يستبعد التقرير جميع ملاحظات War Room الخاصة والملاحظات الخاصة الموروثة، حتى عندما يعده المدير. ملف كامل يتطلب صلاحية تنزيل الأدلة؛ نسخة metadata_only_v1 تقتصر على الإحصاءات والحالة، ولا تصلح لاعتماد الإغلاق.
- بصمة مستقلة لـJSON المعياري ولكل ملف؛ ملفات التقرير مشفرة بمفتاح التخزين. توجد triggers تمنع تعديل snapshot والملفات عبر المسارات العادية. لا تعني البصمة منع مسؤول قاعدة بيانات مميز من العبث.
- الاعتماد يطابق إصدار القضية، ويلزم مراجع آخر؛ استثناء مراجعة المؤلف نفسه متاح للمدير مع سبب مفصل مسجل. لا استثناء يتجاوز الأدلة والمهام والتحقق الإلزامي عند الإغلاق.
- تغييرات المهام والأدلة والعضويات والربط والملاحظات وATT&CK تبطل مطابقة التقرير السابق، مع حفظ النسخ القديمة. الإغلاق مشروط بمعالجة مكتملة وتقرير معتمد حالي، وإعادة الفتح تتطلب سببًا. واجهة transitions الموروثة لا تتجاوز هذه الضوابط.
- القياسات تعرض فروق أوقات موثقة بدليل داخل القضية، ولا تحول وقت استيراد لوق إلى وقت اكتشاف فعلي. القيم الناقصة والسالبة غير قابلة للحساب؛ ليست متوسطات MTTD/MTTR مؤسسية.

## التشغيل والعزل

- `python run.py` يشغل خادم التطوير وعامل الاستيراد وعامل التقارير مع المفاتيح المحفوظة وقاعدة البيانات نفسها. يحافظ على قاعدة root الموجودة ولا يولد مفاتيح جديدة عند إعادة التشغيل.
- PDF/DOCX خارج طلب HTTP في عملية spawn بحد CPU وذاكرة وملفات ووقت جدار. السماح بموارد PDF مقصور على بايتات خطوط SOCify المرفقة؛ لا file/http URLs. اعتراض socket في عملية التحليل دفاع إضافي وليس عزل نظام تشغيل.
- مهام محفوظة، lease وإعادة محاولة محدودة، إلغاء يمنع حفظ النتيجة، وإعادة فحص صلاحية المؤلف قبل العمل والحفظ.
- Compose يخصص شبكة داخلية للتطبيق وnetwork_mode:none للعاملين، مستخدمًا غير root ونظام ملفات للقراءة وحدود موارد. استُبدلت خدمة عامل التدريب المحاكي بخدمة التقارير التشغيلية؛ كود التدريب وتاريخه محفوظان.
- استُبعدت instance وملفات البيئة وقواعد البيانات والتغطية وnode_modules من سياق بناء الصورة لتجنب تضمين مفاتيح أو بيانات تطوير.
- تحقق الحاويات في هذا الوسط لم يكتمل: فشلت شبكة build في حل اسم proxy الخاص بالبيئة. لا يُسجل ذلك نجاحًا للعزل أو النشر، ويلزم إكمال فحص Docker الفعلي.

تحديث لاحق: عولجت بيئة البناء بشهادة الثقة دون تعطيل TLS، واكتمل تحقق stack وتشغيل HTTP والعمال في [دليل 2026-10-25](v3-investigation-local-analysis-2026-10-25.md). يبقى نص الفشل أعلاه سجلًا لنقطة الحفظ السابقة.

## الاختبارات والأدلة

آخر تشغيل شامل: **468 اختبارًا ناجحًا، وتغطية 90.80%** مع multiprocessing، و**11 رحلة Chromium ناجحة** في تشغيل المجموعة الموحدة. Ruff وmypy وBandit وفق إعدادات المستودع وsyntax لملفات JavaScript اجتازت؛ استثناء B608 الموجود مسبقًا لا يُعد إثباتًا ضد SQL injection، وتبقى الاستعلامات الجديدة مربوطة بمعاملات مع identifiers من قوائم ثابتة.

- `tests/integration/test_autopsy_procedures.py`: إصدار القالب، تثبيت نسخة القضية، الصلاحيات، الدليل والاعتماد، الحالات غير الصالحة والقضية المغلقة.
- `tests/integration/test_autopsy_reports.py`: إنشاء snapshot ثم worker حقيقي منفصل، الصيغ الخمس، بصماتها، تشفيرها، حجب الملاحظات الخاصة، ثبات القديم، الاعتماد والإغلاق وإعادة الفتح، منع legacy override، redaction وBOLA.
- `tests/security/test_autopsy_report_security.py`: HTML/Markdown injection وBidi، رفض موارد PDF غير المرفقة، DOCX بلا روابط خارجية، فشل العامل وسحب الوصول والإلغاء والـlease المنتهي.
- `tests/integration/test_autopsy_local_services.py`: worker مستقل يفك أصل الاستيراد بالمفتاح المشترك ويحدث قضية HTTP نفسها، وحفظ المفاتيح وقاعدة قديمة.
- رحلة Chromium جديدة بمدير مع CSRF فعّال: إنشاء/نشر قالب، إنشاء قضية، توليد تقرير وعامل فعلي وتنزيل PDF، axe و360/768/1440/1920 دون تجاوز العرض أو أخطاء JavaScript.
- التغطية تشمل عمليات multiprocessing الفعلية الآن؛ لم يُخفض حد 90% ولم تُحذف اختبارات قديمة.
