# نموذج التهديد

## الأصول

- الحسابات والجلسات وعوامل المصادقة.
- السجلات والأدلة والعينات ونتائج التحقيق والتقارير.
- مفاتيح المصادر والتشفير وإعدادات الاتصال.
- القواعد وحزم التحليل ومصادرها وبصماتها.
- سجل التدقيق والنسخ الاحتياطية.

## حدود الثقة

- المتصفح والملفات المرفوعة والاستعلامات والمصادر الخارجية مدخلات غير موثوقة.
- الوصول يمر عبر صلاحيات الخادم ومساحة الفريق ونطاق القضية والدليل.
- خدمة التحليل معزولة عن الشبكة وقاعدة البيانات ومفاتيح التطبيق.
- يعمل عمال الاستيراد والتقارير والإجراءات بهويات وخدمات مستقلة، مع احتفاظ حالة العمل في القاعدة.
- مسؤول المضيف ومدير الأسرار يستطيعان التأثير في البيانات؛ الحماية داخل التطبيق لا تستبدل حماية المضيف.

## التهديدات والضوابط

| الخطر | الضوابط الموجودة |
|---|---|
| انتحال الحساب أو الجلسة | تجزئة كلمات المرور، MFA، انتهاء الجلسات وإلغاؤها، وحدود محاولات الدخول |
| تعديل الأدلة أو إنكار الإجراء | بصمات، سلسلة عهدة، سجل تدقيق، ومحتوى تقرير محفوظ وقت إنشائه |
| كشف بيانات قضية أخرى | صلاحيات الخادم ومساحة العمل ونطاق القضية والاستيراد والتنزيل |
| تصعيد الصلاحيات | أدوار محددة، تحقق عند كل طلب، وموافقات ومراجعة مستقلة حسب المسار |
| حقن SQL أو HTML أو صيغ CSV | معاملات SQL، تحليل استعلامات مقيد، إخراج نص آمن، وحماية تصدير CSV |
| ملفات أو استعلامات تستنزف الموارد | حدود الحجم والصفوف والعمق والوقت، طوابير محدودة، وعزل التحليل |
| SSRF أو تبديل وجهة المصدر | HTTPS، قائمة مضيفين، تدقيق DNS وتثبيت العناوين، ومنع إعادة التوجيه |
| تكرار الطلب أو التنفيذ | مفاتيح إعادة المحاولة في المسارات المدعومة، منع التكرار، وحجوزات العمال |
| اعتماد أو حزمة تحليل ضارة | اعتماديات محددة، تحقق المصدر والبصمة، اختبارات حزم محلية، وفحص أمني آلي |

## إساءة الاستخدام

- يُرفض مرجع دليل أو أصل أو مهمة لا ينتمي إلى القضية.
- تُرفض أوامر كتيبات الاستجابة غير المدعومة؛ لا يوجد منفذ أوامر shell أو تحكم حي بالأجهزة.
- لا يثبت نجاح الاستيراد إلا قبول البيانات؛ الإعداد وحده لا يمثل اتصالًا ناجحًا.
- يُرفض التقرير القديم لاعتماد الحالة الحالية إذا تغيرت القضية.
- تبقى حدود التحليل والعزل فعالة عند الطلب غير الصحيح أو تعطل الخدمة.

## حدود متبقية

- SQLite يتطلب تخزينًا محليًا متوافقًا مع WAL؛ اختبر تنافس الكتابة وحجم العمل في بيئتك. لا يوجد بديل PostgreSQL مدمج.
- التحليل الساكن لا يثبت جميع سلوكيات ملف، وبيانات الحزم لا تشمل فك TLS أو إعادة تجميع TCP.
- دقة الكشف تعتمد على السجلات المتاحة وتغطية القواعد؛ التنبيه يحتاج حكم المحلل.
- فقد مفتاح الاعتماد يمنع فك البيانات المرتبطة به؛ النسخة الاحتياطية للقاعدة وحدها لا تكفي.
- اختبارات المنصة لا تعوض اختبار إعداد الشبكة والوكيل والمضيف الفعلي.
