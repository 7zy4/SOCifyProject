# سيناريوهات الفرز السريع المرجعية (V6 Use Cases)

أمثلة عملية لكيفية استخدام SOCify V6 كـ**سكين سويسرية** للفرز الأولي السريع (عمق 1، سطح 10):

## 1. بلاغ بريد تصيد ومرفق مشبوه خارج أوقات الدوام
- **المعطيات:** رسالة `.eml` مبلّغ عنها مع مرفق مستند أو ملف مضغوط وسجلات دخول من نظام السيم.
- **مسار الفرز في V6:** فتح قضية مباشرة -> فحص `.eml` والمرفق بضغطة زر ساكناً بدون تشغيله -> استخراج عنوان المرسل والروابط وعناوين الـ IP وإضافتها لقائمة المراقبة (`Watchlist`) -> مطابقتها مع سجلات الدخول -> تعبئة القوائم المنسدلة وطباعة التقرير أو تصعيده للمدير في دقائق.

## 2. فرز دفعة سجلات SIEM لتنبيه هجوم كلمات مرور أو أوامر مشبوهة
- **المعطيات:** دفعة سجلات مسحوبة من SIEM أو مربوطة مباشرة تحتوي محاولات دخول فاشلة من `198.51.100.20` يتبعها تسلسل `winword.exe → powershell.exe`.
- **مسار الفرز في V6:** استيعاب السجلات -> انطلاق تنبيهات القواعد المدمجة تلقائياً (`Brute Force` + `Suspicious Child Process`) -> تثبيت المؤشرات في قائمة المراقبة -> اختيار الحكم والتوصية من القوائم المنسدلة وتصعيد التقرير الجاهز للطباعة.

## 3. تحديات CTF وتحليل ملف لوقز سريع على جهاز محلي
- **المعطيات:** ملف `EVTX` أو `PCAP` أو `Web Access Log` في تحدي استجابة للحوادث دون رغبة في تنصيب بيئة SIEM كاملة.
- **مسار الفرز في V6:** تشغيل الأداة محلياً بأمر واحد -> رفع الملفات لاستخراج التنبيهات والمؤشرات والخط الزمني الأولي -> تحديد النقطة المشبوهة بدقة للانتقال إلى أداة متخصصة عميقة فقط عند الحاجة.
