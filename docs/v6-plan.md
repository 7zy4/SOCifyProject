# خطة تطوير SOCify V6 — منصة الفرز والتحقيق الأمني السريع (Tactical SOC Workbench)

**الهدف العام:** تحويل المنصة من بيئة محاكاة/حوكمة بيروقراطية ثقيلة إلى **"سكين سويسرية" تكتيكية سريعة (عمق 1، سطح 10)** لمحللي ومديري SOC والمحققين وتحديات التحليل السريع (CTF)؛ تعمل مباشرة على ويندوز ولينكس وماك دون اشتراط حاويات Docker للفحص الساكن أو طباعة التقارير، وتختصر الرحلة من استلام السجلات أو البريد المشبوه إلى تقرير مطبوع ومصعّد للمدير في دقائق.

## المراحل المعتمدة للتنفيذ على فرع `V6`

1. **المرحلة 1 — الهوية الجديدة ووصف المشروع (`SOCify Tactical Workbench` / `SOC / V6`):**
   - تحديث اسم المنتج والوصف التعريفي والترويسات وملفات التوثيق ومواصفات OpenAPI وكتالوج الترجمة الثنائي من هوية المحاكاة/التشريح البيروقراطي القديم إلى هوية الفرز والتحقيق السريع.
2. **المرحلة 2 — إلغاء موافقة المدير المسبقة واستلام ملكية القضايا مباشرة (Direct Ownership):**
   - تمكين المحلل والمحقق من إنشاء قضية والعمل عليها فوراً أو استلام ملكية (`Claim Ownership`) أي قضية مفتوحة في الفريق بضغطة زر دون انتظار موافقة مسبقة أو حصر العمل بقضيتين.
3. **المرحلة 3 — ربط سجلات SIEM مباشرة + حزمة قواعد الكشف المدمجة الفورية:**
   - فتح وتفعيل موصل استقبال السجلات المباشر (`HTTP/Webhook Ingest` و`Pull`) بجانب رفع الملفات (8 صيغ مدعومة)، وزرع حزمة قواعد SOC مدمجة (15+ قاعدة عملية) تنتج التنبيهات تلقائياً فور دخول السجلات.
4. **المرحلة 4 — الفحص الأولي الساكن والآمن للملفات ومرفقات البريد بضغطة زر:**
   - فحص أي ملف أو مرفق `.eml` ساكناً بدون تشغيله وبدون اشتراط Docker (البصمات، تطابق النوع السحري `Magic Bytes` مع الامتداد، الإنتروبيا، مؤشرات `PE/Macro/PDF/ZIP/Scripts`، والروابط والعناوين المدمجة).
5. **المرحلة 5 — قائمة المراقبة المرنة (Suspicious Emails & IPs Watchlist):**
   - قائمة حية يضيف إليها المحلل الإيميلات وعناوين الـ IP والنطاقات والبصمات المشبوهة، تفحص السجلات تلقائياً عند الاستيراد أو رجعياً بضغطة زر عند الرجوع إليها.
6. **المرحلة 6 — التقرير المنسدل السريع القابل للطباعة والتصعيد المباشر للمدير:**
   - استبيان موجّه بقوائم منسدلة (8–10 أسئلة سريعة تختصر وقت الكتابة) يعبّئ تلقائياً تقريراً نظيفاً جاهزاً للطباعة الفورية من المتصفح (`A4 Print`) مع زر تصعيد مباشر لصندوق مدير مركز العمليات.
