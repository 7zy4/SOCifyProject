# تجربة V4: خطوات ونتائج متوقعة

ابدأ بحساب المدير من دليل الدخول الخاص بالحزمة. جميع الأسماء والسجلات والعينات وهمية. يوجد أربعة مستخدمين وأربع قضايا صغيرة: التحقيق الأساسي 1، مرتبطه 2، طلب معلق 3، وتحقيق مستقل 4 للمدير وحده. تتضمن القاعدة 33 سجلًا: 31 في القضية الأساسية منها 24 سجل خط أساس، وسجلًا في كل من القضيتين 2 و4. هذا العدد الصغير يتيح تشغيل اختبار الشذوذ الذي يحتاج 20 سجلًا سابقًا على الأقل.

| الوظيفة | التجربة | النتيجة المتوقعة |
| --- | --- | --- |
| صفحة البداية | ادخل بالمدير وافتح القضايا | أربع بطاقات، طلب 3 معطل للاختيار؛ عرض واحد للقضايا دون جدول مكرر |
| نطاق واحد | اختر القضية 1 وابدأ التحقيق | ملخصها وفريقها ومهامها وهدفها؛ اسم القضية النشطة في الأعلى |
| نطاق مزدوج | ارجع للقضايا واختر 1 و2 | يُقبل الربط الموجود؛ تبقى الأدلة والتقارير منفصلة؛ المراقبة تجمع تنبيهاتهما ضمن قنوات الحالة |
| قضية غير مرتبطة | اختر 1 | لا يمكن إضافة 4 كنطاق مزدوج؛ API يرفض زوجًا بلا علاقة أيضًا |
| المراقبة | افتح المراقبة واختر قناة التحقيق، ثم القناة الرئيسية | تنبيهات القضية 1 قيد التحقيق؛ القضية 2 في الرئيسية. ابحث وفرز ووسع تفاصيل التنبيه |
| بحث IP | إدارة السجلات، القضية 1، ابحث `198.51.100.42` | سجلات الويب وDNS والمنع المرتبطة فقط، دون سجل القضية 4 |
| بحث رابط | ابحث `https://invoice-update.test/review` | سجلات تحتوي الرابط المحفوظ. الرابط لا يُفتح تلقائيًا |
| البحث السلبي | ابحث `PRIVATE-UNRELATED-BACKUP` في القضية 1 | صفر نتائج؛ الوصول المباشر لسجلات القضية 4 من جلسة النطاق 1/2 يرجع 403 للمدير و404 للمحلل |
| الاستيراد | اختر JSON أو CSV من fixtures، عاين البصمة وراجع ربط الحقول ثم اعتمد | حفظ الأصل المشفر وعدّ الصفوف؛ إعادة الملف نفسه تُكتشف دون مضاعفة الأدلة |
| الأدلة | افحص تفاصيل سجل ثم اختَره كدليل | بصمة SHA-256 ومصدر محفوظ وحركة حيازة؛ تصدير JSON/CSV/JSONL يعمل ضمن البحث |
| الأصول | أمن الأجهزة | FINANCE-07 مشتبه، بوابة البريد مفحوصة في نطاق موثق، IDP-01 لم يفحص؛ بيانات مالك ونظام وأهمية |
| المؤشرات | استخبارات التهديدات | IP/domain/hash من الاستيراد، وأربعة مؤشرات محقق تتضمن URL؛ مصدر الإثراء محلي وهمي مع ثقة وصلاحية وبصمة |
| عدم وجود تطابق | افحص IP روتيني `192.0.2.20` | عدم تطابق في الحزمة؛ لا يصنفه النظام آمنًا تلقائيًا |
| البريد | أمن البريد | EML محفوظ ومحلل؛ رؤوس SPF/DMARC مرصودة كبيانات غير متحقق منها، رابط ومرفق ببصمته، دون HTML نشط |
| التحليل البسيط | تحليل العينات، افحص النتيجة المحفوظة أو أعد تحليل `invoice-marker.txt` بحزمة Synthetic invoice marker | تطابق `SOCify_Demo_Invoice`، بصمات ونصوص وحجم وقيود التحليل. محتوى العينة نص آمن لا ينفذ |
| YARA | مكتبة التحليل المحلي | حزمة منشورة مع مثال إيجابي وسلبي مرّا بالتحقق المعزول؛ يمكن نشر إصدار جديد بحساب المدير |
| Sigma | مكتبة التحليل المحلي | قاعدة Synthetic invoice campaign منشورة، أمثلتها موثقة؛ سجلات Invoice تطلق تنبيهات محلية |
| الشذوذ | تحليل العينات، التحليل المحلي، mode=anomaly وafter_id=24 في الحزمة المسلمة | نتيجة جاهزة: 24 سجل خط أساس، فحص 7 سجلات لاحقة، أزواج IP/hostname جديدة. الجِدة ليست إثباتًا على خبث كل سجل |
| إعادة القواعد | التحليل المحلي mode=rules وafter_id=0 | نتيجة جاهزة لفحص 31 سجلًا؛ إزالة ازدواج التنبيهات محفوظة |
| التحقيق | تبويب التحقيق والخط الزمني | تسلسل البريد والنقر والاتصال، فرضية مفتوحة وأقدم نشاط محفوظ وسبب جذري بفرع لماذا؟، رسم علاقات وMITRE |
| غرفة التحقيق | تبويب التحقيق | قرار فريق موثق مع الدليل؛ يمكن إضافة ملاحظة خاصة لا تدخل التقرير المشترك |
| الاستجابة | تبويب الاستجابة | تصعيد L1→L2 إلى ريم، إجراء احتواء مخطط، تصحيح مسند، كتيب منشور وأربع خطوات، وSLA أربع ساعات |
| المهام | بدل إلى المحلل وافتح مهامي | مهمة دفعة فعلية مع تعليمات بحث، ومهام القضية داخل ملخصها؛ الإكمال يحدّث التاريخ |
| التقرير | التقارير، القضية 1 | نسخة فعلية محفوظة وصيغ JSON/HTML/MD/DOCX/PDF مولّدة؛ المدير/المحلل ينزلان الكامل، المراجع يرى المراجعة ضمن دوره |
| إصدار جديد | عدّل ملاحظة ثم أنشئ تقريرًا فوريًا | نسخة جديدة مستقلة؛ النسخة السابقة لا تتغير؛ تحتاج مراجعة جديدة |
| اعتماد التقرير | بحساب المراجع افتح نسخة المدير | اعتماد تقرير طرف آخر وفق صلاحية reports.approve؛ لا اعتماد طلب قضية أو رفع عينة |
| الحيازة | تبويب الحيازة والنشاط | سلسلة بصمات متسقة وحركات الاعتماد والأدلة والتحليل؛ لا تعديل تاريخها عبر API |
| الكبسولة | التقارير ← تصدير حزمة الفريق، ثم مكتبة التحليل ← استعادة | قضية جديدة بانتظار اعتماد محلي، مع حفظ الأرشيف وعدم الوثوق بالاعتمادات الخارجية |
| الاعتماد | افتح الطلب 3 بحساب المدير، وثّق السبب واعتمد | يصبح قابلًا للاختيار. قبل ذلك كل أدواته مقفلة؛ رفض طلب جديد يبقيه مقفلًا |
| التبديل | أيقونة السهمين، اختر عمر/ريم/سلمان | جلسة جديدة، القضايا الخاصة بالدور، دون نطاق سابق. عند العودة للمدير يرى القضية 4 |
| عزل الصلاحيات | المحلل يطلب اعتماد قضية أو دخول القضية 4 | 403 للاعتماد، 404 للقضية غير المصرح بها؛ إخفاء الأزرار تؤكده ضوابط الخادم |
| اللغة والجوال | بدّل English والثيم، ثم عرض 390px | RTL/LTR صحيح، الأدلة تبقى كما هي، القوائم والنوافذ ولوحة المفاتيح تعمل دون تمرير أفقي عام |

لتكرار البداية بحالتها الأصلية استخدم نسخة جديدة من الحزمة أو شغّل `prepare_v4_demo` في مجلد جديد. لا تمسح قاعدة تجربة تعمل عليها؛ التهيئة ترفض الكتابة فوقها. تغيير الحساب لا يغير كلمات مرور الحسابات ولا يلغي القرارات المحفوظة.
