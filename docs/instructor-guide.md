# دليل التمارين وتحديات الفرز السريع (CTF & Triage Packs)

يدعم SOCify V6 استخدام المنصة كأداة فرز وتحقيق أولي سريع في تحديات التحليل الأمني (CTF) وحزم السجلات التدريبية أو الاختبارية، بحيث يلتقط المحقق الخيط الأول بسرعة قبل استخدام الأدوات الثقيلة المتخصصة عند الحاجة.

## تجهيز حزمة سجلات أو تحدي فرز

- يمكن استيراد أي حزمة سجلات حقيقية منقّحة أو اصطناعية بصيغ `JSON/JSONL` أو `CSV` أو `Syslog` أو `EVTX` أو `Sysmon XML` أو `PCAP`، بالإضافة إلى رسائل البريد المحجورة `.eml` والعينات الساكنة.
- تعمل القواعد المدمجة وقائمة المراقبة (`Watchlist`) تلقائياً لإبراز المؤشرات الأولية (محاولات الدخول المتكررة، أوامر `PowerShell` المشبوهة، تسلسل العمليات غير المعتاد، أو ترويسات ومرفقات البريد المخادعة).

## ضوابط السلامة عند مشاركة العينات والتحديات

- استخدم نطاقات التوثيق القياسية (`.test` وعناوين `RFC 5737` مثل `198.51.100.0/24` و`203.0.113.0/24`) عند إعداد أمثلة عامة للنشر.
- لا تدرج بيانات اعتماد حقيقية أو عناوين بريد ضحايا فعليين في ملفات أمثلة عامة مرفوعة إلى Git.
- يظل فحص الملفات والمرفقات داخل SOCify فحصاً ساكناً بلا تنفيذ (`never executed`) وبلا استعلامات شبكية خارجية تلقائية.
